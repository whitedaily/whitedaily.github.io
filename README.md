# White 工作台 · GitHub Pages 静态版

纯静态部署，零服务器、零成本、零绑卡。数据存浏览器本地，手机可「添加到主屏幕」当 App 用。

## 鉴权模式说明
GitHub Pages 没有后端，工作台会自动进入 **客户端登录模式**：
- 密码用 SHA-256 哈希保存在本浏览器；可选接入 WebAuthn（面容/指纹）。
- 所有数据（待办、进度、布局等）存在当前浏览器的 `localStorage`，**不跨设备同步**。
- 换设备、清缓存、用无痕模式会导致数据丢失 —— 建议用工作台内的「导出」功能定期备份。

> 相比服务端鉴权版，这是把「安全边界」从服务器降到了浏览器本机。对个人单机使用足够安全，但数据不再集中保存在服务器上。

## 部署步骤（在你本机或让助手推送均可）
1. 在 GitHub 新建仓库，**仓库名必须**为 `<你的用户名>.github.io`（例如 `white.github.io`）。
2. 把本目录全部内容推送到该仓库的 `main` 分支（根目录）。
3. 等待 1–2 分钟，访问 `https://<你的用户名>.github.io` 即可。
4. 首次打开会要求创建账户（用户名默认 White，密码 ≥6 位）；之后每次需登录。

## 手机安装
浏览器打开页面 → 菜单「安装应用 / 添加到主屏幕」→ 桌面出现 White 图标，离线也能启动外壳。

## 目录
- `index.html` —— 工作台主页面（即 `xin-workbench.html`）
- `manifest.webmanifest` / `sw.js` / `icon-*.png` / `favicon.png` —— PWA 资源（根路径）
- `.nojekyll` —— 关闭 Jekyll 处理，确保以上文件原样 served

> 本目录只包含前端静态文件，不含 `server/`（无后端）。需要服务端强鉴权版请另用容器平台部署。
